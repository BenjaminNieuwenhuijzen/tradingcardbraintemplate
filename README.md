# TradingCardBrain

Je eigen dashboard voor je kaartencollectie, gratis en altijd bereikbaar op je telefoon. Het volgt de waarde van je PriceCharting collectie, laat trends zien en denkt mee over wat slim is om te ruilen. Bij elk advies staan de reden en de cijfers.

**Zelf installeren?** Klik op **Use this template** en volg [SETUP.md](SETUP.md). Je hoeft niets te programmeren en je hebt geen creditcard nodig. Je kiest alleen zelf een wachtwoord voor je dashboard.

## Goed om te weten

* Je krijgt je eigen privé kopie. Niemand anders ziet je gegevens.
* Je dashboard is afgeschermd, alleen jij kunt erin.
* Reparaties en verbeteringen komen vanzelf bij je binnen.
* De prijsgeschiedenis komt in kleine porties per dag binnen, dus de eerste weken wordt je dashboard steeds vollediger.

Prijzen komen van [PriceCharting](https://www.pricecharting.com) en zijn daar eigendom van. Dit project is niet verbonden met PriceCharting en bedoeld voor eigen gebruik.
